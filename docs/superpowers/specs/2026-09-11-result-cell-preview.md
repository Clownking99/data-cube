# 查询结果单元格查看

基线 main `b8487aa`，独立 `codex/result-cell-preview`。本轮改善“查询之后读懂一个值”，不增加数据库执行、数据编辑、导出格式或持久化。

## 产品约定

- 结果工具栏“查看单元格”和右键“查看当前单元格”显式打开只读窗口。先选择数据单元格；多选时查看仍在选区中的焦点单元格，不猜测另一格，不支持序号列/隐藏列/空白行。
- 通过当前表格行对象身份映射到不可变结果快照，列使用原始位置，不按标题或可见序号猜测。排序、本地筛选、列重排/隐藏以及重复列名后仍查看准确值。
- 显示当前显示行号、结果原行号、原列号、列名、JDBC 类型和只读文本，区分数据库 NULL、空字符串与字符串 `NULL`。正文是原有格式化规则的显示表示，不宣称是原始数据库字节或完整 LOB。
- 正文最多 65,536 UTF-16 单元，不拆开代理对，超限明确显示已截断和显示表示长度。列名/类型名保留最多前 512 单元，超出时追加省略号和说明；元数据过高时可滚动。特殊结果值提示可能已在读取时截断，不补取内容。
- 可选择文本和手动 Ctrl+C，自动换行默认开启、只改此窗口显示；不自动复制、执行、保存、读取元数据、解析/运行 HTML 或 JSON。只显示打开时的快照，不随新查询、筛选或焦点变化改值。
- 没有结果/选中数据格时给出固定提示。关闭、运行/排队、根节点禁用、非结果表格视图或已终结时拒绝旧入口。FX 终结关闭已有查看窗口，单个 SQL 标签不重复开多个查看窗口。

## 实施与验证

1. 有界纯快照模型、只读可缩放窗口。
2. 结果工具栏和现有 Pane 的薄接入，不扫描整个结果集来定位单格。
3. 精确测试：NULL/空/文字/特殊值、限额、位置映射、快照隔离、生命周期和布局；独占临时文件与网络 probe。
4. 全量 clean test / jpackageImage，隔离合成结果窗口进行明暗、鼠标、长文本实测。
5. 审阅、更新 README/路线和验收记录，本地提交后快进 main；不推送/tag/发布，不触碰 `.testagent/`。
