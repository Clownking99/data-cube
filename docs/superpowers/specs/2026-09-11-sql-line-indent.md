# SQL 行缩进

基线：本地 main `c204396`；独立 `codex/sql-line-indent`。本轮只改善编辑效率，不扩展 SQL 执行、连接或持久化格式。

## 行为

- 工具栏“缩进”“反缩进”，默认可改绑 Ctrl+] / Ctrl+[，仅编辑器接收按键；不改变 Tab / Shift+Tab 和补全约定。
- 无选区处理光标所在逻辑行；有选区处理涉及的整行，末端恰在下一行行首时不处理下一行。反向选区同规则，结果保留方向及内容位置；被删除空白内的位置收敛到行首。
- 缩进在每行前插入 4 个 ASCII 空格；反缩进移除一个行首 Tab 或最多 4 个行首 ASCII 空格，不删除其他空白。空行可缩进；全文选区不包含末尾空行，光标位于末尾空行时可以单独处理。
- 这不是 SQL 格式化或语法解析：多行字符串内的行首空白也会改变。用户需检查结果，不能宣称 SQL 语义不变。
- 只提交行首补丁，作为一个独立可撤销编辑；无变化不增加撤销记录。保留文件身份、原有物理换行，正常标记未保存并沿用草稿检查点，不自动保存 SQL 文件或执行。
- 文本与结果最多 8 Mi UTF-16 单元，单次最多涉及 10,000 行；超限整体拒绝并提示缩小范围，无部分应用。
- 非可编辑/禁用、草稿冻结、关闭准入、资源关闭、任务关闭、文件忙碌时拒绝旧动作；销毁后移除快捷键与设置监听。
