# 表/视图生成 SELECT 草稿

基线 main `4ace548`，v3.2.4 的 Verify 与 Build and Release 已于 GitHub 成功。
当前树可以定位对象，但表的“打开 SQL 编辑器”仍为空，视图没有生成查询入口。
本轮补齐找到对象后开始写查询的衔接；不声称有用户耗时或需求排名数据。

- PostgreSQL / Oracle 的表、视图右键提供“生成 SELECT 到新 SQL（不执行）”；不替换已有查看数据、空白编辑器、DDL、导出或编辑动作。
- 生成 `SELECT *` 和完整双引号引用的 Schema / 对象名，内部双引号加倍。按元数据原样保留大小写、空格和点号，不把名称解析为 SQL 片段，不读取列清单。
- 名称必须非空、最多 1,024 UTF-16 单元；拒绝控制字符、Unicode 行/段分隔符和孤立代理项，不截断/清洗为另一个对象名。Redis 和非表/视图不提供入口。
- 菜单绑定当时的具体节点，不依赖当前选择；单元格复用不改变原菜单目标，刷新、删除、节点值替换或面板关闭后旧菜单不生效。配置变更时拒绝旧目标，不借用活动连接。
- 新标签绑定所选连接的离线意图，使用现有脚本连接选择及首次执行锁定规则；生成时不创建 provider/JDBC 会话、预热元数据、执行查询或写 SQL 历史。
- SQL 自带 Schema 限定，Schema 输入保持空，不添加隐含会话命令。执行必须由用户显式触发，沿用原有安全检查与结果行数上限。
- 使用既有受管标签、文件和草稿生命周期；初始模板为未绑定文件的干净基线（与历史载入一致），编辑后有未保存标记，首次保存进入另存为。生成的文本可进入既有本地恢复检查点，不自动保存到 `.sql` 文件。
- 验证纯生成、真实菜单路径与标签事务、目标连接隔离、特殊名称、关闭/刷新边界、零数据库访问；全量测试与开发镜像后做隔离桌面验收。
- 独立 worktree 完成后快进本地 main；不推送/tag/发布，不读取或修改用户 `.testagent/`。不扩展为对象远端搜索、列选择或写入 SQL 生成器。
