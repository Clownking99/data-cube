# 批量结果双向异常定位

基线 main `f124008`。已有“下一异常”能循环查看失败，但回看刚才的异常需要绕过其他错误或重新在下拉框查找。本轮补齐逆向入口，不增加 SQL 执行能力。

- “本次结果”旁按顺序提供“上一异常 / 下一异常 / 执行详情”；从概览向前进入最后一个已保留异常，向后进入第一个。
- 两个方向均按原始执行顺序跳过正常查询/更新，包含失败、超时、取消，首尾循环。当前唯一异常时同时禁用；不重复重置当前视图或详情。
- 导航按保留列表位置及快照身份选择，不因相同 SQL、编号或等值结果跳错；不受概览排序/筛选影响。只切换已返回结果，不自动弹详情，不修改编辑器、文件、撤销、连接或 Schema。
- 保留原有前 1,000 条上限；省略异常仍计入总汇，但不能导航到未保留数据。新结果、忙碌、关闭及过期动作沿用原有守卫。
- 不增加快捷键，不改持久化、依赖、数据库协议或普通结果操作。窄栏仍保留结果选择器的最小宽度，并校验两个主题下控件完整且不重叠。

步骤：扩展已有导航测试覆盖双向行为、身份和保留上限，先 RED → 单控制器最小实现 → 定向与全量测试、开发镜像 → 自审提交、本地快进 main 并复验。使用合成快照与隔离临时文件，不读取真实连接/SQL/历史/剪贴板或 `.testagent/`。

本轮不重试已受限的桌面通道。JavaFX 自动布局和事件验证不等于原生鼠标/键盘验收；新增按钮的原生交互与此前 SQL 摘要/耗时表头待验项一起保留。只做本地集成，不推送、不打 tag。
