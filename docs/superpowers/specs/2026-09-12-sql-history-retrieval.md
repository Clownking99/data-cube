# SQL 历史找回体验

基线 main `3e75c77`，独立 `codex/sql-history-retrieval`。现有历史已有连接/schema/SQL 子串过滤，但无匹配状态、无选择打开保护，列表空白双击也会返回旧选择。本轮集中补齐这个已有入口，不引入历史删除、收藏或新的持久化格式。

## 交互约定

- 对打开时最多 200 条历史快照进行字面子串匹配；忽略首尾空白，使用 Locale.ROOT 忽略大小写。保持原有最近在前顺序，搜索连接名、schema 和完整 SQL，不解析或执行 SQL。
- 显示“显示 N / M 条历史”；区别真正暂无历史与过滤无结果。无结果时预览清空、打开禁用；清除筛选恢复列表。
- 筛选后原选中条目仍可见则保留，否则选择首条；不让索引移动误选其他历史。输入只更新本地候选与预览。
- 初始聚焦筛选；Ctrl+F 回到筛选并全选；筛选框按向下键进入列表；筛选框/列表 Enter 或“打开到新 SQL”确认。预览 Enter 不打开；Esc/取消返回空结果。
- 只有有效条目上的主键双击打开被点击的条目；空白、空单元格、右键双击不打开旧选择。
- 预览只读，弹窗可调整大小，说明明确“仅载入新 SQL 标签，不自动连接或执行”。沿用 AppShell 已有隔离空会话载入路径，不新增网络、文件写入、剪贴板或全局快捷键监听。

## 验证与交付

测试技能按单个对话框的聚焦范围使用，行为矩阵写入验收记录；不增加通用技能流程文件或触碰用户 `.testagent/`。先证明缺失状态红灯，再测试匹配/选择/确认/取消/鼠标与键盘、明暗窄窗口；全量 clean test 与开发镜像、隔离合成历史桌面验收。完成后提交、快进本地 main 并定向回归，不推送或打 tag。
