# SQL 重复行

基线 main `6eac2d4`（v3.2.5），独立 `codex/sql-duplicate-lines`。已核实该版本发布流水线成功。本轮参考 [DBeaver 重复选中整行并移动到副本](https://dbeaver.com/docs/dbeaver/Shortcuts/) 的编辑工作流，DataCube 使用工具栏“重复行”和可改绑 Ctrl+Shift+D；不声称有真实用户效率实验。

## 约定

- 无选区时复制当前逻辑行到下方，光标保持行内偏移；有选区时复制覆盖的整行，并把原选区及方向移动到副本。选区末端恰好位于下一行行首时不包含该行。软换行不改变范围。
- 包含空行和末尾空行；无终止换行的最后一行先插入分隔符，避免拼接语句。仅复制文本，不解释 SQL；字符串、注释及危险语句同样会被复制，真正执行前必须检查范围与内容。
- 不用系统剪贴板，不自动执行、连接、保存源文件。原文仅发生一次插入，原有物理换行保留；新增换行沿用已有 SqlScriptDocument 的首个分隔符约定（无分隔符时 LF），不承诺混合换行片段的副本逐字节相同。
- 纯计划只接受 CodeArea 的 LF 规范化文本与合法 UTF-16 偏移。输入/结果最多 8 Mi UTF-16 单元，最多复制 10,000 行；超限整体拒绝、不改选区/撤销。不截断文本。
- 一次撤销，与相邻键入分开；保留文件身份、未保存提示和草稿检查点。重复后的选区仍遵循现有“执行选中/全部”规则，不自动执行。
- 控件和快捷键共享动作；仅编辑器内匹配快捷键，设置改绑即时生效。关闭、资源回收、文件忙碌、草稿冻结、不可编辑或父级禁用时不修改，提交前再次检查。补全弹窗收起，关闭时解除键盘/设置监听。

## 实施与验证

1. 实际 Pane 入口缺失红灯；独立纯计划、编辑动作及最小 Pane/ShortcutAction 接线。
2. 表驱动覆盖当前/跨行/反向/末端行首/空行/末行/Unicode，精确文本与选区、限额前后；真实 CodeArea 单步撤销、快捷键改绑与守卫。
3. 实际 Pane + 临时文件/草稿/连接探针验证持久化边界、执行范围及明暗窄栏；全量 clean test、开发镜像和隔离桌面验收。
4. 差异自审、本地提交/快进 main、合并后定向回归；不推送、打 tag 或改动 `.testagent/`。

按本机协作约定，测试技能的行为矩阵和 Java 指南用于本增量；不额外套用多代理、内部状态文件或重复报告模板。
