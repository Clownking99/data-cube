# 执行概览仅看异常

基线 main `8861fea`。大量正常语句会挤占批量执行概览，已有“下一异常”适合逐条跳转，本轮补齐集中检查异常摘要的入口。

- 概览增加“仅看异常”复选框，默认关闭；开启后仅显示已保留的失败、超时和取消，不包括查询与更新。
- 显示“当前可见 / 已保留”计数，零匹配明确说明“已保留结果中没有异常”，不将保留上限之外的异常误报为不存在。原批次总汇与下拉选择器不变，仍最多保留前 1,000 条。
- 保持当前排序；所选行仍可见则按对象身份保留选择，被隐藏则清除选择、禁用详情与查看结果，不自动改选其他语句。过滤变化关闭旧详情。
- 查看结果、Enter 详情仍对应原始快照，不按筛选后的行号或 SQL 文本匹配。
- 条件只用于当前概览；离开概览、新批次、清空、计划或关闭时重置，不持久化。忙碌或关闭状态下迟到动作不能过滤或恢复旧结果。
- 不执行 SQL、不改变编辑器/选区/撤销/源文件，不访问真实连接、历史或剪贴板。

步骤：失败回归 → 单控制器最小实现 → 定向/全量测试及开发镜像 → 隔离真实编辑器桌面 → 自审、提交、快进本地 main 并复验。不操作 `.testagent/`，不推送、不打 tag。
