# SQL 编辑器显示换行

基线 main `beb1c55`，独立分支 `codex/sql-editor-wrap`。
现有编辑器为长 SQL 提供水平滚动，但尚无显示折行入口；本轮提供可选的长行阅读方式，不改变 SQL 格式。这是基于现有工作流的产品假设，不声称已经测得用户耗时改善。

- SQL 编辑器底栏新增“自动换行”复选框，默认关闭；仅影响当前标签，其他标签和新标签不继承，不新增设置、草稿或工作区持久化字段。
- 使用 RichTextFX 的显示换行属性，不插入换行符、不格式化文本、不改变选区方向/光标偏移、逻辑行号、执行范围或撤销/重做历史。原始文件换行与未保存状态保持不变。
- 提示明确“仅调整显示，不修改 SQL；行号仍按原始文本计算”。换行后的视觉行不是 SQL 文本行；查找和跳转到行沿用原规则。
- 开关只改变视图，不连接数据库、预热元数据、执行 SQL、更换目标、保存文件或写系统剪贴板。关闭/退出冻结及资源关闭后旧动作不生效；取消关闭恢复后可继续切换。
- 使用已有可折行的底栏，窄窗口下允许控件换行，不能压缩成省略标签。保持键盘 Tab/Space 可用，不新增或占用快捷键。
- 不扩展至 DDL/结果区/其他编辑器，不做全局字体、缩放或文本编辑重构，不推送/tag/发布；`.testagent/` 不读取、修改或暂存。

实施顺序：底栏行为回归 → 接入显示开关及关闭守卫 → 文件/被动连接集成验证 → 全量测试和开发镜像 → 隔离桌面验证长行、明暗/窄栏及标签独立 → 审查、提交、本地快进 main。
