# 查询结果紧凑行

基线 main `010a97c`，独立 `codex/result-compact-rows`。上轮合成结果实测中，多行单元格撑高整行；本轮提供可选的单行预览，帮助连续浏览，并沿用单元格查看器阅读详细内容。这是工作流假设，不是用户效率实验结论。

## 产品约定

- 结果工具栏新增“紧凑行”复选框，默认关闭，仅当前 SQL 标签有效；同标签新结果沿用，不持久化、不影响其他标签。
- 开启后每格只显示首行或前 256 UTF-16 单元。遇到换行附 ` ↵ …`，长度截断附 ` …`，不切断代理对。CR/LF/CRLF、NEL、Unicode 行/段分隔符、VT/FF 均按换行处理。关闭恢复原显示规则。
- 只改变 TableCell 文本呈现，不改原值、结果行对象、行列排序、列宽、隐藏状态、筛选或选择；不重新发布结果。行高随字体自然计算，不硬编码固定像素高度。
- 复制、导出和“查看单元格”继续读取原快照；不得把预览标记混入内容。没有数据库、网络、剪贴板、SQL 编辑或文件写入副作用。
- 无查询结果时禁用；运行/排队/关闭/终结/禁用/执行计划期间拒绝旧动作并恢复选框实际状态。清空结果只禁用，不重置用户选择。
- 本轮不扩展到对象数据网格、不做持久化偏好、数据编辑、LOB 补取或发布。

## 实施和验收

1. 提取纯文本单行预览规则、当前标签显示控制器；接入现有表格 cellFactory 和可换行工具栏。
2. 为文本边界、实际虚拟化 cell 重用/行高、标签隔离、状态拒绝、原值复制/导出/查看和排序筛选组合补回归；既有 Java 25 / JUnit 5 / Gradle，不新增依赖。
3. 定向与全量 clean test / 开发镜像；使用上轮无连接合成 fixture 和独占 profile 验收明暗切换及菜单读取原值。
4. 更新 README、路线图与证据；审查后本地提交、快进 main，再运行 main 定向回归。不推送/tag/发布，不触碰用户 `.testagent/`。
