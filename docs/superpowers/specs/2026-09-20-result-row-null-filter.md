# 行详情隐藏 NULL 字段

## 产品范围

宽表行详情中，数据库 NULL 字段可能占据大量阅读空间。在已有按字段名筛选旁增加默认关闭的“隐藏 NULL 字段”，与名称条件取交集。它是当前行已捕获可见字段快照的阅读筛选，不是原查询筛选，不查询数据库、不改变原表或复制/导出范围。

- 只判断 `ResultCellPreview.nullValue()`，空字符串、空白、数字零和文字 NULL 保留；不按格式化文本猜测 NULL。
- 保持原快照顺序与原列号；仍显示总快照字段数。初始只捕获前 200 个可见字段，筛选后不从未捕获字段补齐。
- 当前字段仍符合条件时保留字段身份、正文选区与正文查找状态；被排除时清空详情，不代选同名或其他字段。恢复列表不自动恢复选择，用户明确选取后继续阅读。
- 原“清空”改为“清除筛选”：同时清除字段名和隐藏 NULL 条件，不清正文查找词。任一条件生效时按钮可用。
- 名称超长仍整体拒绝；NULL 开关不能绕过 256 UTF-16 单元限制。无匹配使用条件范围内的空状态，不说数据库没有数据。
- 设置只在本窗口有效，关闭重开默认不隐藏；保留原 Ctrl+F、Ctrl+Alt+F、Enter/Down、Esc，复选框支持原生 Tab/Space。

## 实施与验收

从 main `7c7efe4` 创建独立 `codex/result-row-null-filter`，仅修改 `ResultRowDialog` 生产逻辑。按聚焦测试流程先复现缺失入口，再覆盖真假 NULL、组合条件/重复名称、有效选择保留/失效清理、零匹配、字段截断、清除、重新打开与原结果不变；复跑既有行详情和正文查找测试、全量测试、开发打包。用独立合成 fixture 通过 computer-use 进行明暗窄窗及鼠标/键盘交互验证，再合回本地 main。不推送、不打 tag，不读取 `.testagent/` 或真实用户连接/SQL/剪贴板。
