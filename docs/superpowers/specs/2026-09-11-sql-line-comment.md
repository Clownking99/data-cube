# SQL 行注释入口与编辑可靠性

基线 main `803bfb1`，独立 `codex/sql-line-comment`。现有 Ctrl+/ 和可改绑设置已存在，本轮不是新增快捷键，而是补充可见入口及修正整行重写/选区扩大的编辑行为。[DBeaver 官方说明](https://dbeaver.com/docs/dbeaver/SQL-Formatting/)确认其同时提供显式行注释入口及 Ctrl+/，仅作为交互参考，不推断真实用户需求排名。

## 决策与范围

- 缩进/反缩进旁增加“行注释”按钮，提示“切换当前行或选中行注释”、当前快捷键及文本编辑边界；沿用 SQL_LINE_COMMENT，不新增配置字段。块注释规则不在本轮变更范围。
- 无选区仅作用于当前物理行，保持折叠光标；有选区处理触及的物理行，末端恰在下一行行首时不包含该行，保持正/反向方向。添加注释时起点必须包含首行新标记，只有缩进的选区也至少覆盖新标记，防止“执行选中”绕过首行注释或回退全文；其余端点按字符位置映射，不扩展为整行。UI 提示此范围调整，取消注释则移除前缀并映射端点。
- 忽略空行和仅含空格/Tab 的行。若所有非空行在行首空格/Tab 后已有 `--`，移除一层 `--` 及其后最多一个普通空格；否则在每个非空行缩进之后插入 `-- `，包括已有注释行。保留缩进、行内空白、Unicode 和换行分隔符，不用 String.join 重建整行。
- 只按行文本编辑，不解析 SQL 语义；在多行字符串、块注释内部操作也会改文本，不承诺 SQL 语义保持，也不能代替执行前核对。
- 仅生成原始 UTF-16 偏移的小段编辑，最多 8 Mi 输入/结果单元及 10,000 行，超限全部拒绝。空白无操作不污染撤销；一次切换作为独立撤销步，与前后输入分隔。
- 始终检查只读编辑器、禁用及父禁用、草稿冻结、关闭准入/资源/任务、文件读写忙碌；准备完成后重新检查，不应用过期编辑。生产连接的只读属性不禁止离线编辑文本。快捷键不作用于其他输入框。
- 沿用文档脏标记、标题星号、混合物理换行映射及草稿检查点；不自动保存源文件、连接数据库、读取元数据或执行 SQL。

## 分步实施

1. SqlLineComment 纯计划器：当前/选中行、前缀、位置映射、限额；先写模型测试。
2. SqlLineCommentAction：按钮、动态提示、批量编辑、守卫、关闭；Pane 的旧行注释方法改为委托，共用按钮/快捷键执行路径。
3. 纯模型、CodeArea 行为、实际 Pane 文件/草稿/被动连接和生命周期回归；现有块注释/缩进/冻结测试继续运行。
4. 全量 clean test、独立开发镜像、合成桌面明暗/窄栏/点击与撤销检查；差异审阅后本地提交、快进 main 并回归。不推送/tag/发布，不触碰用户 `.testagent/`、真实配置或业务数据。
