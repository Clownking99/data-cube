# 执行概览直接查看结果

## 目标与边界

在执行概览选中摘要后点击“查看结果”，直接显示对应语句已经返回的查询数据、影响行数或错误。无需在下拉框重复寻找，不重新执行 SQL。Enter 仍打开只读执行详情。

- 按快照对象身份定位，不按表格行号、语句编号或 SQL 文本匹配；排序、重复编号与重复 SQL 不会串结果。
- 沿用结果选择器的查询来源 SQL / Schema、导出与筛选逻辑；切换结果重置该视图的筛选和列布局。
- 沿用前 1,000 条结果保留上限；概览无选择、忙碌、关闭、旧批次或外来行不能导航。
- 不访问真实连接、SQL 文件、历史或剪贴板；仅使用合成结果和一次性桌面配置目录。

## 推进步骤

1. 在独立 worktree 先加入行为回归，确认缺失入口导致失败。
2. 增加概览按钮与受保护的快照身份导航，保持现有详情入口不变。
3. 验证排序、各结果类型、来源与撤销不变、失效/忙碌保护和明暗窄栏布局。
4. 全量测试、开发镜像与隔离桌面验证；记录结果后提交并本地快进 main。不推送、不打 tag。
