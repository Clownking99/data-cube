# 结果表按当前显示行号定位

基线 main `136092f`，独立 `codex/result-row-locate`。[DBeaver 结果导航](https://dbeaver.com/docs/dbeaver/Navigation/) 的 Go to Row 提供工作流参照；DataCube 本轮只操作已显示结果，不引入滚动补查或数据库分页。动机是减少长结果中的反复滚动，尚无真实用户耗时实验。

## 行为与安全边界

- 结果表右键增加“定位到行…”；不扩张主工具栏或重绑 SQL 编辑器的 Ctrl+G。打开、输入和取消不改变结果选择、焦点、排序、筛选、SQL 或文件。
- 行号是当前筛选并排序后的 1..N 显示顺序，与结果表序号列一致，不是原始结果行号、主键或数据库总行数。不加载更多行，不隐式提交防抖搜索文字。
- 默认值为当前焦点行（无有效行时为 1），输入框聚焦并全选。接受两端空白及带前导零的 ASCII 十进制正整数；原输入最多 32 UTF-16 单元，数值最多 10 位；空白、零、负数、小数、指数、非 ASCII 数字、越界或超长整体拒绝，Enter 不关闭。提示范围和副作用，不回显原始输入。
- 明确确认后清除旧多选，选中目标行的打开时可见焦点数据列；没有有效数据列焦点则取第一个可见数据列。不选择序号列、不显示隐藏列。只滚动并聚焦此数据格；数据、排序、筛选、列宽/顺序、SQL、撤销与文件不变。Enter 确认，Esc 取消。
- 捕获打开时的 rows 列表对象和列身份，不复制结果正文。行列表替换/增删/重排、可见列变化均使窗口永久失效；确认时再次检查 active/displayedResult 身份、来源行映射、列索引和忙碌/关闭守卫。失效或不允许时不做部分定位，须重开。
- 一页最多一个定位窗口；标签最终关闭一并关闭。监听在窗口隐藏时解绑，不被 owner 的 onHidden 覆盖；旧按钮即使直接派发事件也不改变结果。
- 所有验证使用合成结果及临时配置，不访问真实数据库、历史、凭证或 `.testagent/`。不增加依赖、后台任务或持久化。
