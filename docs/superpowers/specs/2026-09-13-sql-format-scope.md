# SQL 美化范围与撤销

## 问题与选择

基线 main `0798b8e`：`SqlEditorPane.onFormat()` 总是读取并替换全文，有选区时也会修改其他语句。
本轮延续高频 SQL 编辑工作流，复用现有 `SqlFormatter` 排版，不引入外部服务或数据库请求。
参考 [DBeaver 选区格式化](https://dbeaver.com/docs/dbeaver/SQL-Formatting/) 的显式范围，
快捷键采用 [DataGrip Ctrl+Alt+L](https://www.jetbrains.com/help/datagrip/reference-keymap-win-default.html)。
初案 Ctrl+Shift+F 在桌面验收中进入 JavaFX 时为 UNDEFINED，而 Ctrl+Alt+L 正常触发；不修改系统输入法设置。
不以参考工具或合成验收推断真实用户效率。

## 行为

- 无选区：按钮“美化全文”；有任何非空选区：按钮“美化选中”。空白选区不回退全文、不编辑。
- 新增可改绑 Ctrl+Alt+L，仅编辑器内生效；按钮、快捷键共用同一动作。
- 仅替换范围内去掉首尾空白后的正文；保留选区外文本及范围首尾空白，防止吞掉相邻分隔符。
- 美化选中后仍选中对应范围，保留正向/反向；全文美化不建立新选区，光标按原字符偏移夹紧。
- 一次美化独立为一次撤销；无变化不增加撤销记录、不移动选区。维持语法高亮、草稿和文件未保存提示。
- 美化期间抑制自动补全，并取消旧的排队候选；不因程序化替换调用成员候选供给器。后续用户输入和 Ctrl+Space 保持可用。
- 保存/关闭/退出冻结、不可编辑/禁用、会话操作期间均拒绝；应用前复核正文、选区和准入，丢弃过期计划。
- 单次美化范围最多 256 Ki UTF-16 单元，编辑器原文及结果最多 8 Mi UTF-16 单元；超限整体拒绝。
- 这是现有词法美化器的文本排版，不是方言完整语法校验或语义保证。建议选择完整语句，执行前检查结果。
- 不执行 SQL、不自动保存源文件、不改连接/事务、不访问剪贴板；不修改 SQL 文件或恢复格式。

1. 在实际 Pane 的合成文件测试中复现选区被扩大、空白选区改全文。
2. 抽出纯范围计划与独立 FX 动作，只在 Pane 接入生命周期与高亮；增加快捷键枚举。
3. 验证正反选区、边界空白、无变化/空文本、限额、异常、单步撤销/重做、快捷键作用域/改绑、过期回调。
4. 实际 Pane 验证混合换行的选区外保留、文件身份/脏标记、草稿、零 provider/session/metadata/network，明暗窄栏。
5. 全量测试、Windows 镜像和隔离合成桌面验收；审查后提交并本地合并 main，不推送、不打 tag。

`.testagent/` 及真实用户配置/连接/SQL 历史不在范围内。具体证据单独记录，不把自动化替代实际桌面。
