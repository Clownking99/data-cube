# 连接树显式查找

基线 main `7e1ab3b`。当前连接树只有 1.2 秒重置的键入检索，缺少持久输入与前后定位入口。
本轮改善已有树中的名称定位，不宣称已有用户调研、任务耗时或需求排名证据。

- 左栏常驻查找框；输入忽略首尾空白、大小写，按名称字面包含匹配，不重建/隐藏树节点。
- 只检查当前展开链上的节点，包括连接、Schema、分类及对象；不搜索折叠分支、数据库内容或未加载对象，不自动展开/连接/查询。
- 输入仅更新匹配数；Enter/下一处、Shift+Enter/上一处、F3/Shift+F3 才从当前选中位置循环定位。选中连接沿用原活动连接语义，不打开数据页或执行 SQL。
- 树内 Ctrl+F 聚焦查找框；清除按钮和 Esc 清除关键字，保留树的选中项、结构与展开状态；Esc 返回树。
- 保留原有直接键入快速定位。加载中和错误状态行不作为显式查找结果。
- 关键字最多 256 个 UTF-16 单元，输入防抖 180ms；单次顺序扫描最多 10,000 个已展开节点（包括状态行），超过时明确说明只检查前 10,000 个节点。使用迭代遍历，不对每一行调用树索引查找。
- 展开/折叠、异步加载、名称变化、刷新替换和删除后失效旧结果；定位时同步复核当前树，不选中已经脱离树的旧节点。关闭后排队回调不得改 UI 或选择。
- 明暗 240/280/400px 左栏下输入和操作可用；不修改连接配置、凭据、数据库、SQL 标签或事务。

## 实施与验收

1. 独立显式查找组件，受限已展开遍历、定位和生命周期，不接入数据库服务。
2. 连接树接入并保留旧键入检索；合成树验证不自动展开/加载，真实 ConnectionTreePane 验证不创建连接或调用对象动作。
3. 定向、全量、开发镜像；隔离合成连接进行桌面键盘、清除和窄栏验收。未执行项单列。
4. 审查后提交、合并回本地 main；不推送、不打 tag、不发布，不读取或处理用户 `.testagent/`。
