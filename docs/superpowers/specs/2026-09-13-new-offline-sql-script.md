# 新建离线 SQL 脚本

基线 main `6ee55aa`，独立分支 `codex/sql-new-script`。

## 决策与边界

现有“新建 SQL”沿用左栏活动连接；文件、历史及恢复入口已有显式脚本连接，但创建这种独立脚本尚需已有文件或记录。本轮在“SQL 文件”菜单首项增加“新建 SQL 脚本（离线）”，保留原“新建 SQL”语义，不添加快捷键或改绑冲突。这是代码工作流支持的小步假设，不是用户需求排名或耗时测量。

每次点击新建独立空白标签，标题 `SQL - 新脚本`，不覆盖或复用已有编辑器。使用空 SessionContext 和既有被动脚本模式，Schema 为空；初始无连接且执行禁用，不跟随左栏，不连接、预热元数据或执行 SQL。通过现有可搜索“选择脚本连接”确认 PG/Oracle；选择本身仍保持离线，目标失效/首次准入锁定沿用已有守卫。

标签通过现有 managed-tab、文件控制器和草稿生命周期安装：初始干净且无文件路径；编辑后显示未保存状态，首次保存进入另存为；取消保留文本和未绑定状态。连接选择不写文件，打开不写最近文件/历史。编辑使用既有草稿检查点；正常关闭仍沿用原有历史规则，不承诺永不记录。关闭取消保留标签，应用关闭门控拒绝新建。失败释放本次资源，不新增持久化格式或执行路径。
