# 多语句脚本执行详情

## 用户问题与范围

批量执行摘要无法查看对应 SQL，错误只显示前 80 字，混合失败仍显示绿色。增加批量结果专属的「执行详情」入口，选择摘要行后查看只读 SQL、结果类型、耗时、行数和错误。表格排序后仍对应原语句序号。

仅解释已返回的结果，不宣称全部脚本已执行或事务已提交；取消/超时不等于回滚。不执行 SQL、不补查结果、不写文件、不新增持久化。单查询数据表及单语句原流程不变；本轮不做多个查询数据集切换。

## 边界与交互

- 汇总统计所有返回项，分别显示正常、失败、超时、取消；有异常不显示绿色。
- 最多展示前 1000 条摘要；每段 SQL/错误最多 16384 UTF-16 单元，合计文本预算 1048576 单元。截断不切断代理对，界面明确提示省略。
- 详情快照仅包含文本、枚举及数字，不保留 QueryResult、查询行/字段对象或连接。查询行数为已加载行数，保留结果截断标记；未知更新行数明确说明。
- 批量摘要出现时才展示入口。用户选择摘要后点击按钮，或在表格按 Enter。不自动打开、不自动复制；详情仅显示纯文本，Esc 关闭。
- 使用摘要行对象身份映射详情，不用排序后的行号索引原列表。新结果、执行计划、清空、错误和关闭会清除旧详情并关闭弹窗；无效新查询不能提前丢弃当前摘要。
- 关闭中、任务域关闭、禁用、执行中及会话操作待完成时，旧事件不得打开详情。

## 验收

先用真实 SqlEditorPane 混合错误摘要复现红灯，再覆盖纯模型计数/边界、排序映射、只读内容、替换/关闭/禁用和离线文件不变。执行全量测试、打包，并用隔离无连接桌面夹具验证暗/亮主题、窄窗和弹窗键盘操作。完成后提交并合并本地 main；本轮不推送、不打 tag。
