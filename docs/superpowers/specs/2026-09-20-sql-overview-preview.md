# 执行概览 SQL 摘要

基线 main `d3707dc`。现有概览只有编号、类型、耗时和结果，辨认对应语句需要逐条打开详情。本轮增加只读 SQL 摘要列，帮助先识别语句再检查结果；不把它当作可执行 SQL 或完整正文。

- 列位于“耗时”和“结果”之间，显示已捕获 SQL 的前 120 UTF-16 单元；将换行和制表符转换为空格、去除首尾空白，不解析 SQL、不删除注释、不合并普通空格，不拆开代理字符对。
- 摘要或原始有界快照被截断时显示省略号；未提供/空白 SQL 和因报告总预算省略的 SQL 分别明确提示。沿用每字段 16,384、总文本 1,048,576、前 1,000 条的既有上限，不读取被省略尾部。
- 详情仍展示原始有界 SQL，编辑器后续修改不影响已执行快照；摘要排序、异常筛选后“查看结果”和 Enter 详情仍按快照身份定位。
- 普通查询结果不增加摘要列，切换结果/新批次仍释放旧概览。窄窗使用表格横向滚动，不挤压操作按钮或自动改选语句。
- 不执行 SQL、不改文件/草稿/选区/撤销，不访问真实连接、历史、系统剪贴板或 `.testagent/`；不新增复制、导出或自动重执行入口。

步骤：概览缺列回归 → 有界摘要与列接线 → 单元及集成回归 → 全量测试/开发镜像 → 隔离桌面 → 自审提交、快进本地 main 并复验。本轮不推送、不打 tag。

集成顺序调整：桌面访问连续失败时，停止 UI 重试；此只读展示增量在自动验证通过后先本地集成及复验，桌面验收单独保留为未完成项，不等同于可发布。具体结果与待验清单见[验收记录](../verification/2026-09-20-sql-overview-preview.md)。
