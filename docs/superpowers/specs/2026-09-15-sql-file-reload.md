# SQL 文件重新加载

## 问题与决策

已有保存会拒绝覆盖被外部修改的文件，但用户无法在当前标签直接载入磁盘新版。本轮增加「重新加载」按钮，仅针对已绑定本机文件的 SQL 标签。不增加自动文件监视、自动合并或自动执行。

每次操作都确认：用磁盘内容替换编辑器，丢弃未保存修改并清空撤销/重做记录；默认取消。用户可先取消再另存为。无文件的离线/历史/恢复标签不可操作，首次成功保存后即可用。

读取复用 SqlScriptFileStore 的 UTF-8（含 BOM）、8 MiB、稳定读取与规范路径检查，在工作线程运行；原保存冲突检测不放宽。读取后更新原标签的磁盘基线与精确换行，光标/选区夹紧到新长度。下一次保存仍检查新版是否再次被外部修改。

不写 SQL 文件、不改最近列表、不连接/读元数据/执行 SQL，不改变目标、Schema、事务、已显示结果或布局。新文本沿用既有草稿机制，抑制自动补全。关闭查找/替换/跳转条，防止旧替换任务应用。

## 状态与保护

- 与保存/另存为共用文件操作准入及 busy 生命周期，重复点击不并发。
- 确认取消、读取失败、编码/大小不符、规范路径发生变化：保持旧正文/基线/选区/撤销，显示固定错误，不泄露路径或异常文本。
- 用文本修订号拒绝确认或读取期间的编辑（包括编辑后撤销回原文），不覆盖新工作。
- 关闭、任务域关闭、禁用、草稿冻结、运行中及会话操作待完成/停止接收：旧事件和迟到回调不得应用。
- 成功刷新标题/保存基线，清空撤销；无新文件绑定，不释放或转移路径所有权。

## 分步验证

1. 真实文件标签缺少入口 RED；补控制器读取及 Pane 按钮/确认。
2. 控制器确定性任务队列：取消、成功、失败、晚编辑、关闭、守卫变化、保存冲突与重试。
3. 真实 Pane 的按钮、只读副作用边界、草稿/补全/布局与窄栏；全量测试及镜像。
4. 隔离合成文件桌面验收；提交、本地合并 main、主分支回归与镜像核对。本轮不推送、不打 tag。
