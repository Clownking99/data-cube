# 多语句结果与执行反馈修复

基线 main `07be400`。对应用户报告的三项实际问题，不扩展到新数据库或自动执行。

1. 批量执行保留已返回的逐条结果，提供“执行概览 / 语句 #N”切换，默认展示第一条查询数据；没有查询则展示概览。查询沿用结果表、当前结果筛选/列控制/查看/导出；切换仅渲染内存数据，不重新执行。更新与失败项展示对应影响行数或错误，批次失败汇总持续可见，不把部分失败说成全部成功。新执行结果、清空、执行计划和关闭释放上一批引用；执行中禁止切换。沿用概览前 1,000 项上限并明确提示，不复制 JDBC 结果或取消每次查询原有行数上限。
2. Oracle 和 PostgreSQL 执行器只在失败且存在后续可执行语句时调用继续策略。单条/最后一条/仅尾随注释不询问；取消仍立即终止。保留继续、全部继续、终止以及手动事务遇错停止规则。
3. 高亮和自动补全使用同一关键字词表，补充 CASCADE、CONSTRAINTS 等常用 DDL 词；词边界包含数据库标识符的 $/#，字符串、注释及带引号标识符不当关键字。不宣称实现完整 Oracle 语法解析。

每项先失败回归、再实现，完成定向/全量测试和隔离桌面验收后提交、本地快进 main。不访问或更改 `.testagent/`、真实连接、业务数据、系统剪贴板；不推送或打 tag。按项目约定只使用测试技能的相关设计与验证指导，不附加通用流水线。
