# 当前结果行详情（只读）

基线 main `2c36f7f`，独立 `codex/result-row-preview`。列查找解决“找到一列”，本轮解决“纵向核对同一条记录的可见字段”。这是合成宽表操作后的产品选择，不宣称真实用户需求排名或耗时收益。

## 交互与边界

- 结果右键“查看当前行（可见列）”，不增加顶层按钮。明确使用当前已选择的焦点数据格所属行，不猜第一选中行，也不根据行内容相等替换身份；无有效选择给出选择提示。
- 当前筛选、排序、列重排后按行对象身份/原始列索引捕获；只包含当前可见数据列，排除序号和隐藏列。初选焦点列（若位于展示限额内），否则首字段。
- 对话框字段列表按当前可见顺序纵向展示“原列号 · 列名”和首行预览，选择字段后显示只读正文、JDBC 类型及 NULL/空字符串/特殊类型/截断说明。切换字段只改详情窗口，不更改原表选择、筛选、排序、列宽/顺序或 SQL。
- 打开时生成独立有界文本快照，不持有 JDBC、整个 QueryResult 或可变 TableView；后续新结果/清空/列变化不更改已打开详情。关闭标签/最终 UI 清理时关闭窗口，单标签不重复打开行详情。
- 最多展示前 200 个可见字段，每字段正文最多 4,096 UTF-16 单元（合计最多 819,200），元数据沿用每项 512 限制；不拆代理对。超列/超正文分别明确提示。较长单元格可关闭详情后使用原“查看单元格”，也不承诺完整 LOB。
- 仅含当前可见字段；隐藏字段需用户回到原表明确显示后重新打开，不在详情中悄悄展示。详情可以手动选文本复制，没有自动复制、编辑、保存、导出、查询、前后行导航或数据库动作。
- 正文可切换自动换行，Escape 关闭；列名单行化避免换行污染列表，正文仍保留原换行。明暗、窄窗说明和动作可读。
- 忙碌/排队、关闭准入、资源或任务关闭、禁用、执行计划和过期结果拒绝旧入口；不提交仍待防抖的本地搜索。

## 实施与验收

1. 独立 ResultRowPreview 负责可见列投影、限制和不可变快照；复用 ResultCellPreview 的格式/类型语义，新增仅包内的有界捕获入口，保持单元格原上限不变。
2. ResultRowDialog 负责纵向字段浏览/只读正文；Pane 只负责入口、现有焦点身份解析及关闭清理，不增加存储或并发逻辑。
3. 纯模型、实际 JavaFX 窗口、实际 Pane 的筛选/排序/同名/隐藏交叉、生命周期、防抖和零网络探针。无新增依赖、无 .testagent 写入，行为矩阵与真实命令记在本轮验收文档。
4. 定向、全量 clean test、开发镜像及隔离合成桌面检查；审阅后本地提交并快进 main，再回归。不推送/tag/发布。
