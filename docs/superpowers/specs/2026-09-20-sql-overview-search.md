# 执行概览按 SQL 摘要筛选

基线 main `0a419a0`。批量结果已有 SQL 摘要、耗时排序及异常筛选，但语句较多时仍需逐行寻找表名。本轮只补本地摘要关键词筛选，不扩展执行能力。

- 概览增加“筛选 SQL 摘要”输入框及“清除关键词”。忽略大小写和首尾空白，按字面包含匹配，不使用正则/通配符；只匹配当前已显示的 SQL 摘要（含省略标记/空值提示），不搜索完整 SQL、错误、结果数据、编辑器后改内容或前 1,000 条之外的记录。
- 输入最多 256 UTF-16 单元；超长输入整体拒绝，保留之前条件、结果和选择，并给出提示。清除关键词不取消“仅看异常”。不新增快捷键，不占用编辑器 Ctrl+F 或概览表格 Enter。
- 与“仅看异常”取交集，显示可见/已保留计数，零匹配明确限定摘要及异常范围。沿用当前排序；可见选择按原始行身份保留，隐藏选择清空且不代选，清除条件也不复活旧选择。
- 输入条件变化关闭旧详情；筛选后的“查看结果”及 Enter 详情仍对应原始执行快照，不重新执行。离开概览、新结果、清空、关闭时重置关键词和拒绝提示；忙碌/关闭/禁用时拒绝旧输入与清除动作，不恢复旧结果。
- 复用现有 FlowPane 换行，校验明暗主题及 480/640 宽度的完整输入框、按钮和计数；不改变批次导航、汇总、导出、文件、连接、Schema、事务或保存规则。

步骤：单控制器聚焦回归 RED → 最小实现 → 定向/全量测试及开发镜像 → 自审提交并本地快进 main、复验生产模块一致性。只用合成结果和隔离临时文件，不访问真实 SQL/数据库/历史/剪贴板，不操作 `.testagent/`。

本轮不重复尝试已受限的原生桌面通道。自动 JavaFX 事件/布局不替代真实鼠标键盘验收；新增筛选的原生交互与此前待验项保留。不推送、不打 tag、不变更正式版本。
