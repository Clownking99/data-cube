# SQL 上移行 / 下移行

基线 main `4f82a22`，`v3.2.7` 发布成功。自主选择一个文本编辑增量：调整 SELECT 字段、JOIN 或条件顺序时，用一次移动代替剪切再粘贴。这是工作流改善假设，不宣称已有真实用户耗时证据。

- 工具栏独立的“上移行 / 下移行”组，默认编辑器内 `Alt+↑ / Alt+↓`，可在既有快捷键设置改绑；不占用普通方向键、Tab 或其他输入框。
- 无选区移动当前物理文本行；有选区整体移动覆盖行，与相邻一行交换。选区恰好结束于下一行行首时不包含该行。保留行内光标、选区方向及原文本范围，不扩选整行；移动到无终止换行的文件末尾时端点夹紧至 EOF。
- 所选范围已到首行时上移、已到末行时下移，以及单行/空文件均不改文本或撤销。重复内容仍移动光标/选区，但不制造假修改或撤销记录。末尾空行是可移动的行；全文以换行结尾时，选区结束于末尾空行行首不包含该空行，仍可向下交换。
- 只替换各行正文，保留所有分隔位置上的原 CRLF / LF / CR，不新增、删除或统一换行；分隔符不随正文搬移。一次批量编辑、一次撤销，撤销/重做后物理换行、文件身份、脏状态正确；不写源文件，不读写剪贴板。
- 单次最多 10,000 个所选行（可额外交换一个邻行），全文最多 8 Mi UTF-16 单元。超限整体拒绝。算法只解析有界文本与相邻行，不理解 SQL；移动可能改变语义，执行前需检查。
- 沿用草稿、文件忙碌、只读编辑器、禁用、关闭守卫；准备后复核文本与选区，拒绝迟到变化。批量应用期间抑制自动补全请求，不自动执行、连接、保存或改变事务/结果/布局。
- 桌面复验发现撤销移动会触发候选弹窗，补充共享补全监听的撤销/重做保护：回放时隐藏候选并使旧自动请求失效；正常输入和显式 Ctrl+Space 仍可补全。
- 纯文本规划、动作、真实 Pane 分层回归；使用合成文件和内存连接探针。全量测试、开发镜像及隔离桌面通过后提交并本地快进 main。不读取/修改 `.testagent/` 或真实连接、业务 SQL、用户草稿；不推送或打 tag。

依项目约定，测试技能用于这一有界动作的直接回归，不引入通用流水线工件或额外子代理。若桌面不可用，保留代码与测试证据并明确说明未完成的桌面验收。
