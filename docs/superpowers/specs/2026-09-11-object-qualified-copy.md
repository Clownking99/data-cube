# 复制表/视图限定名称

基线 main `025ca85`。已有右键 SELECT 草稿解决新查询；在已有脚本补充 FROM/JOIN 时，仍缺少对象名复用入口。
本轮选择显式复制，不自动插入光标、不替换选区，也不新增执行入口。这是工作流假设，不声称真实用户耗时改善。

- PostgreSQL / Oracle 表、视图菜单增加“复制限定名称”，保留现有动作；不扩展到 Redis、过程、序列或批量选择。
- 纯文本为 `"Schema"."Object"`，无 SELECT、分号或连接信息。共享 SELECT 生成器的标识符规则：分别引用、双引号加倍，保留大小写、点号、空格和 Unicode。
- 拒绝空名称、超过 1,024 UTF-16 单元、控制字符、Unicode 行/段分隔符和孤立代理项，不截断或清洗为另一个名称。
- 仅用户触发动作后写系统剪贴板；不读取其旧内容、不自动粘贴、不上传。系统剪贴板可被其他应用或系统剪贴板同步功能访问，不把它称为私密存储。
- 菜单捕获原节点与所属连接；当前选择或单元格复用不改变目标。删除、刷新、节点替换、连接目标变更或面板关闭后旧菜单不写剪贴板。
- 左栏显示复制结果，只有写入返回 true 才显示成功；拒绝/异常显示通用失败信息，不泄露异常详情。无效输入在写入前拒绝。成功提示提醒粘贴前确认目标连接，复制不修改脚本连接或执行范围。
- 不创建 provider、会话、标签，不请求元数据，不执行 SQL，不写 SQL 历史、草稿或业务文件；复用已加载的内存对象。
- 测试使用注入剪贴板写入器与合成连接；隔离桌面验证实际复制/手动粘贴、明暗与窄栏。保留原 SELECT 生成和连接树查找回归。
- 独立 worktree 完成后本地快进 main；不推送/tag/发版，不读取、修改或暂存 `.testagent/`。

实施顺序：提取纯限定名生成器 → 连接树复制与反馈 → 精确边界/实际菜单测试 → 全量与隔离桌面 → 差异复核、提交和本地合并。
