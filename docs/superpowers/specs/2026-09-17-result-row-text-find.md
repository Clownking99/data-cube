# 行详情：当前字段正文查找

基线 main `10167a6`。在已完成字段名筛选的行详情中补齐长正文定位，不增加 SQL 编辑器主工具栏按钮。改善 JSON、报文、备注阅读是产品假设，未获得真实用户耗时数据。

- 复用单元格只读字面查找条；行详情使用独立控件 ID 和“当前字段正文”提示，不搜索字段名、类型、其他字段、隐藏字段或截断尾部。
- 输入只更新计数，不改变字段或正文选区。支持大小写、上一处/下一处、首尾循环；正文仍为只读的打开时快照。
- 原 Ctrl+F 保留字段名筛选；Ctrl+Alt+F 聚焦正文查找。正文查找框 Enter / Shift+Enter、窗口内 F3 / Shift+F3 定位当前字段，Esc 仍关闭窗口；快捷键也覆盖页脚关闭按钮。不新增快捷键设置、全局键盘监听或剪贴板行为。2026-09-19 原生桌面对照中 Ctrl+F 正常，而最初 Ctrl+Shift+F 未聚焦正文，因此改用 Ctrl+Alt+F；不把可能的系统/输入法冲突当作已证实原因。
- 切换字段保留查找词和大小写选项，重新计算当前正文匹配，不自动跳转。字段名筛选保留原候选时保留正文选区；排除原候选后清空正文和匹配，不选择其他字段。
- 每字段仍最多显示 4,096 UTF-16 单元，最多列出 200 个可见字段；查找词最多 1,024 单元，超限整体拒绝、不搜索其前缀。NULL/空字符串的提示不当作正文。
- 关闭窗口解除新查找监听，即使拥有者覆盖 onHidden 也保持清理；旧按钮不能再定位。原单元格窗口的 ID、快捷键与查找语义保持不变。
- 最小改动：共享查找条仅增加上下文配置，行详情组装入口与键盘路由；合成 Pane 回归证明结果/SQL/文件/连接不变。明暗窄窗与真实键盘用隔离夹具验收。
