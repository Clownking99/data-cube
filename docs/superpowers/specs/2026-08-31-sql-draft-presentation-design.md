# SQL 草稿桌面呈现收尾

用户已授权后续常规产品决策无需逐项确认；本次沿用独立 worktree、验收后本地合并 main 的边界。

## 已观察的问题

2026-08-31 实际 AppShell 隔离桌面验收确认：普通未绑定 SQL 能保存并在新 JVM 恢复，但管理列表把合法空连接类型拼为 `null`，空 Schema 只有前缀；暗色空预览提示过暗。正文、恢复、重复定位、正常退出并未因此失效。

## 方案与决策

采用局部呈现修正：无绑定显示“未绑定连接”；有类型但名称 null/blank 显示“未命名连接 · 类型”；Schema null/blank 显示“Schema: 未指定”。保留时间、有限预览及控制字符净化；不改原始记录。使用已有 `#draft-manager-sql` ID，令提示色引用现有 `-brand-fg-dim`，仅覆盖该只读预览，也覆盖 focused 样式。

对比方案：全局输入框提示色调整会波及连接/编辑器界面，超出本次范围；新增空状态组件需要额外节点和状态同步，本次无需。现有 ID 和主题语义色足以解决问题。

## 边界与验收

- 不改变存储、身份解析、执行、会话、清理、隐私开关或历史记录；不查找真实连接。
- 实际 cell 测试覆盖未绑定、未命名、正常 PostgreSQL/Oracle、空 Schema、空 cell 复用和原值保持。
- 真实样式表计算测试覆盖暗/亮、普通/focused CSS 状态的提示可见及对比至少 4.5:1；选中后正文不受影响，取消选择恢复提示。
- 修改前先观察行为失败，再实现；独立审查、完整回归与打包后进行修正项桌面复验。
- `.testagent/` 保持完全不动；仅合成数据与独占临时目录；本次不推送、tag、安装或发布。
