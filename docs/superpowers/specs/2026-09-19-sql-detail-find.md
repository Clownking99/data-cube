# 执行详情内查找

基线 main `7d5b1df`。批量异常已可定位和打开详情，但长 SQL/错误正文仍需肉眼寻找。此增量基于现有工作流判断，不虚构用户耗时研究。

- 只读执行详情增加一个查找条及显式范围（SQL / 错误信息）；查询和更新只有 SQL 范围，默认范围为 SQL。切换范围保留查找词/大小写设置，重算计数但不主动移动任一正文选区。
- Ctrl+F：从 SQL 或错误正文触发时切到该正文的范围；从其他控件触发时保留所示范围，然后聚焦并全选查找词。F3 / Shift+F3、查找框 Enter / Shift+Enter 及前后按钮在所示范围内定位并循环；额外修饰键不冒充这些快捷键。Esc 仍关闭详情。
- 复用 `ResultCellFindBar` 的字面搜索、空格和 Unicode 语义、1,024 UTF-16 查询上限与前 10,000 处定位上限；支持切换目标 TextArea 时解绑旧监听。只搜索窗口已显示的正文，不搜索身份标签、查询数据、其他语句或截断尾部，不拼接 SQL 和错误跨字段匹配。
- 原报告单字段 16,384 / 总计 1,048,576 UTF-16 保留上限不变，不追加读取/网络/SQL执行，不改编辑器、文件、结果、连接或事务。
- 关闭时清理查找监听/匹配并禁用旧动作，不能被调用方 onHidden 覆盖。重新打开由既有控制器创建新窗口，不继承旧查询。
- 480/880 宽度明暗布局、独立 profile 合成桌面的 Ctrl+F、范围切换、计数/循环和只读选区需验证。
