# Schema 对象类型筛选

基线 main `105a45f`。对象查找已支持名称与复制，但表/视图混合快照在候选较多时缺少按类型缩小范围的入口。本轮为自主选择的产品假设，不是用户研究排名。

- 在已有查找窗口提供「类型：全部 / 仅表 / 仅视图」，默认全部，每次新窗口重置，不新增持久化配置。
- 类型与名称按 AND 组合，只筛已有完整名称快照；先组合筛选，再截取前 200 个展示。匹配数为组合结果，分母始终为此 Schema 已加载对象总数。
- 类型改变不加载元数据、不复制、不生成或执行 SQL。仍匹配的选择保留完整身份；不再匹配则清空选择/预览并禁用复制与确认，不按位置替换成另一对象。清除旧复制反馈。
- 「清除筛选」同时清除名称和类型，只有两者均默认才禁用；不重新请求数据库或清除连接数据。
- 读取期间可先设置类型与名称，成功后应用最新条件；重读和失败重试保留条件但清空旧候选，延迟结果仍沿用 revision/来源/关闭守卫。来源失效时禁用类型。
- 类型选择控件不抢默认确认，原 Ctrl+F / ↓ / Enter / Esc 规则保持；类型下拉打开时 Esc 先关闭下拉，不误关闭整个查找窗口。明暗窄窗不挤掉目标与完整对象身份。

实施：独立 worktree → 入口 RED → 单类实现/定向状态与边界测试 → 全量/开发镜像 → 合成隔离桌面 → 审查、提交并本地快进 main。测试技能用于本类的直接行为矩阵，不创建通用测试流水线工件。保留 `.testagent/`；不访问真实保存连接、业务 SQL、系统剪贴板或数据库，不推送、不打 tag。
