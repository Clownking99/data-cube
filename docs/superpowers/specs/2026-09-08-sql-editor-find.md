# SQL 脚本内查找

## 本轮决策

现有搜索只面向已加载结果行。下一步补齐脚本文本定位，暂不增加替换、正则表达式、
跨文件搜索或批量高亮，避免同时扩大编辑与文件操作边界。

- 编辑器“查找”按钮和可改绑的 `Ctrl+F` 打开内联查找栏。
- 单行、非空且不超过 1,024 个 UTF-16 单元的选中文本可预填；否则保留本标签上次查找词。
- 按字面匹配，默认不区分大小写，可勾选区分大小写。匹配不重叠。
- 输入只更新匹配数量，不自动移动编辑光标。上/下一个或 `Enter` / `Shift+Enter` 显式定位，
  到头循环并提示；`Esc` 或关闭按钮隐藏查找栏并返回编辑器。
- 查询词最多 1,024 个 UTF-16 单元。最多定位前 10,000 处，更多时显示 `10000+` 和缩小范围提示。
- 150ms 防抖，只在查找栏打开时捕获文本并提交后台工作。使用原有任务作用域，
  取消仅针对本次查找 Future；文本、关键词、大小写、隐藏或关闭变化使旧回调失效。
- 查找不改变 SQL、撤销栈、文件 dirty、数据库会话或事务；不保存关键词，不记录 SQL 正文。
- 控件按可用宽度换行，计数和失败提示独占一行并允许折行，不压住编辑文本。

## 实现与验证

独立纯文本匹配器负责 UTF-16 范围、计数上限和可取消扫描；独立 JavaFX 查找栏负责防抖、
请求代次、导航与资源解绑。`SqlEditorPane` 只接入口、快捷键和既有两阶段关闭流程。

用合成文本验证字面符号、Unicode、空/无匹配、大小写、首尾循环、数量/长度边界、取消，
以及真实 CodeArea 的只读导航、编辑后刷新、关闭后的迟到回调和快捷键改绑。
最后运行全量测试和 jpackage 构建，在隔离配置下做桌面验收；不连接真实数据库。
