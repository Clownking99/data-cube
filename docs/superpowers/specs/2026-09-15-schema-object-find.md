# Schema 表/视图检索

基线 main `afae456`。从 PostgreSQL / Oracle 的 Schema 节点右键「查找表/视图…」进入，固定连接与 Schema，后台读取名称和类型；不要求先展开表/视图分类。查询词只在本地筛选名称，不发往数据库。确认「生成 SELECT（不执行）」才复用既有 openSelectSql，保留离线脚本和目标选择规则，不自动查数据、执行或编辑对象。

本轮不做跨 Schema/连接扫描、不改已有已展开节点查找、不建立持久化索引，不查字段/注释/视图正文。现有 views 接口读取定义，因此新增有界的名称专用 SPI；PG/Oracle 使用绑定 Schema 参数、最多 10,001 行及 15 秒 statement timeout，独立连接由读取任务关闭。超过 10,000 个对象整体拒绝，不提供冒充完整索引的部分结果。此限额限制客户端返回，不承诺数据库完全不扫描内部目录；驱动连接/取消也不承诺即时中止。

对话框初始加载、空 Schema、无匹配、失败与重试独立显示；失败不显示原始 JDBC 诊断或部分结果。加载成功后只在内存检索，忽略大小写和首尾空白，最多 256 UTF-16 查询单元；最多展示前 200 个匹配并提示继续缩小范围。输入不代选新对象，仍匹配的选择保留，否则清空；↓ 显式选择，Enter 确认，Ctrl+F 回查找，Esc 取消；只读完整 Schema/名称预览的 Enter 不确认。

菜单捕获准确节点及连接快照，打开前、加载/发布时、确认返回后复核；节点/根替换、连接变更、关闭或取消后旧操作失效。读取使用不可变配置快照，不在任务排队期间按相同 ID 改连另一目标。取消只封闭本次结果并请求中断，不关闭共享连接/运行器。

独立 worktree → 菜单 RED → 有界服务/对话框/最小接入 → 定向及全量测试 → 合成桌面验收 → 本地提交快进 main。使用测试技能直接验证行为，按项目约定不增加通用流水线工件；不碰 `.testagent/`、真实连接或业务数据，不推送、不打 tag。
