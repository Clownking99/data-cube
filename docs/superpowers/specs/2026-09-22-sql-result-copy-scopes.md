# 查询结果按范围快速复制

状态：已实现，等待本地整合。

## 目标

查询结果除了当前单元格、选区和选中行外，提供两个无需手工选中的复制范围：

- 当前筛选行：复制结果表当前显示行，保留本地筛选和表头排序后的顺序。
- 全部已加载行：复制本次查询已经加载到内存的全部行，按结果快照原始顺序输出。

两种范围都提供“含表头”和“不含表头”两个入口。两者均只输出当前可见数据列，沿用列重排和隐藏状态；序号列不复制。

## 边界与安全

- 只读当前 `QueryResult` 与结果表，不重新查询、不访问数据库、不改变筛选、排序、列布局、选区或焦点。
- “全部已加载”不等于数据库全量：若结果已截断，只复制已加载行，并在状态中标注“已加载”。
- 复制结果按 UTF-16 单元限制为 8 MiB；超限时不调用系统剪贴板写入器，显示“请缩小范围或改用导出”。
- 保留现有可注入剪贴板写入边界；系统剪贴板失败仍不报告成功。
- TSV 转义规则沿用现有 `TsvClipboardFormatter`，不会把紧凑行预览标记复制出去。

## 不在本轮范围

- 不新增数据库分页或“加载更多”。
- 不改变文件导出范围、SQL INSERT 复制和现有选区复制语义。
- 不持久化复制范围，不自动选择行，不自动执行 SQL。
