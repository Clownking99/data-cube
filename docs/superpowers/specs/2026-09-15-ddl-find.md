# 只读 DDL 查找

基线 main `45b1929`。补齐查看表/视图 CREATE 定义时的文本定位：工具栏「查找」或面板内 Ctrl+F 展开搜索，选中的单行文本可作为初始词；Enter / Shift+Enter 或上下一个循环定位，Esc 收起并保留选区。

复用 SqlFindBar / SqlTextSearch 的后台字面搜索、150ms 防抖、大小写与整词选项；默认忽略大小写、不启用整词，不去除空格。最多 1,024 UTF-16 查询单元，最多定位前 10,000 处，超限明确提示。只搜索当前已显示 DDL（包括注释/字符串/加载错误文本），不重新读取元数据，不执行 SQL，不搜索其他标签。只读模式不提供任何替换控件，程序调用替换也必须无效；普通 SQL 编辑器保持原行为。

加载完成从首行展示，并使旧文本的搜索结果失效。关闭时先取消任务/封闭回调，再在 FX 线程释放监听器和计时器；不关闭应用共享运行器。窄窗通过可换行工具栏保留操作入口，明暗主题实测。
