# 在对象查找中复制限定名称

基线 main `5b180f8`。现有 Schema 查找只能生成新 SQL；本轮补齐找到对象后复用到已有 SQL 的路径，不扩展对象索引或数据库访问范围。

- 选中候选后提供独立「复制限定名称」按钮，点击才写系统剪贴板，窗口保持打开。保留筛选、候选、预览与生成 SELECT 的既有行为；不自动粘贴、切换目标连接、打开标签或执行。
- 复用已有 ConnectionTreeClipboard 的连接快照检查、SqlObjectNames 引用规则和系统写入器。反馈返回给查找窗口，原连接树复制入口仍保留原反馈，不将弹窗反馈放在被遮挡的左栏。
- 明确系统剪贴板可能被其他应用/系统同步读取，粘贴前须核对目标连接。不会读取剪贴板，不拦截输入或预览的 Ctrl+C。
- 初始、加载、空列表、无匹配、未选择、来源失效、关闭或禁用时不可写入；确认点击时再次校验。刷新或选择/筛选变化清除旧反馈，避免成功提示指向另一候选。
- 写入返回 false 或抛出 RuntimeException 时显示安全失败反馈，允许重试，不谎报成功、不展示原始异常；无效名称或连接变化在写入前拒绝。
- 控件在 480 窄窗明暗主题可见，工具条可换行；复制不产生 Dialog 结果或关闭窗口，预览和复制按钮的 Enter 不误触 SELECT，Esc 保持取消。

独立 worktree、入口 RED、定向行为回归、全量与开发镜像、隔离合成桌面验收、本地提交快进 main。测试技能按本增量直接验证，不引入通用流水线工件；不触碰 `.testagent/`、真实连接、业务 SQL、用户剪贴板或网络，不推送、不打 tag。桌面夹具用内存剪贴板替身展示所写内容，不声称验收系统剪贴板服务。
