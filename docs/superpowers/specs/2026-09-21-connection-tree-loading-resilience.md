# 连接树展开加载可靠性

基线为本地 main `a1ed3ec`。连接树的节点按需异步读取元数据；原实现把首次展开标记为已加载，即使读取失败也不会再尝试，空列表则直接把子节点置空。刷新、编辑或断开连接后，迟到回调也没有显式的当前树代次校验。

本轮只收紧显示和生命周期边界：

- 成功返回空列表时显示“没有可用对象”，不把已展开节点渲染成空白。
- 加载失败时显示错误和“收起后可重试”；只有用户明确收起后再次展开才发起一次新加载，避免重复并发请求。
- 每次 reload、断开替换和关闭都使用当前树代次；已脱离树或旧代次的成功/失败回调不再修改可见节点。
- 不改变连接配置、凭据、SQL、对象查询上限或数据库错误详情策略。后台任务仍由现有 `FxTaskScope` 管理，关闭后不执行 UI 回调。

步骤：新增状态/代次回归 → 接入懒加载 → 定向测试 → 全量测试和镜像构建 → 本地 main 合并。真实连接和用户配置不在验收范围。
