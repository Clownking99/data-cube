# 脚本与草稿连接快速选择

基线 `fb08f8a`，独立分支 `codex/connection-picker-search`。现有 SqlDraftConnectionChooser 仅有下拉框；本轮在同一边界补齐多连接查找，不改 SQL 执行或连接管理。

## 范围与规则

- 共用选择器改为“筛选框 + 匹配计数 + 可见候选列表 + 明确确认”。适用于脚本文件、历史 SQL、恢复草稿；不新增外部数据请求。
- 仅对本次打开时的可用 PostgreSQL/Oracle 配置快照按名称、类型和完整 ID 做字面、Locale.ROOT 忽略大小写筛选，不搜索地址、用户名、密码、附加选项。保留原顺序及现有名称/ID 有界显示。搜索词最多 256 UTF-16 单元，超限整次编辑拒绝。
- 初始不选择。输入即使只匹配一条也不代选；保留仍可见的同一候选，被排除则清空选择，不能按索引落到其他目标。清除筛选不恢复已经隐藏的旧选择。
- Ctrl+F 聚焦筛选；筛选框按 ↓ 明确进入列表并在尚未选择时选第一条；Enter 只确认已选候选，Esc 取消。双击不快捷确认。无候选、无匹配或无选择时确定禁用。
- 沿用调用方确认后的当前配置复核、关闭/忙碌守卫和首次会话锁定。筛选、选择和取消不连接、读取元数据、执行 SQL、修改源文件或更换现有目标；只有明确确认才返回原配置对象。
- 明暗与窄窗入口可见；不添加全局偏好或持久化格式，不显示凭据，不扩大为自动重连或跨库检索。

## 实施与验证

先用缺少筛选入口的行为用例证明旧路径红灯，再实现单一选择器和局部主题规则。测试技能用于精确状态矩阵，按本机约定内联实施，不新增通用流水线或读取用户 `.testagent/`。保留现有文件、历史、恢复流程测试的业务断言，只将控件定位更新为可见列表。完成定向、全量、镜像及隔离合成桌面验收后本地提交并合并 main；本轮不推送或打 tag。
