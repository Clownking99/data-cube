# 查找当前结果列

基线 main `aa5d08d`，独立 `codex/result-column-find`。宽结果的列定位依赖横向滚动/逐项菜单，本轮提供明确确认的本地名称查找，不做数据库对象搜索。

## 产品约定

- 入口放在现有“列”菜单首项“查找列…”中，避免宽表需要滚过长列清单才能使用；不增加顶层工具栏按钮。
- 查找当前结果的全部数据列（含隐藏列、不含序号列），大小写不敏感的字面名称子串匹配，不查结果值、不用正则、不发请求。空词列出当前顺序，重名用原始列号区分。
- 输入最多 256 UTF-16 单元，超长时清空候选并提示缩短；候选最多展示前 200 条，明确总匹配数和需缩小范围。列名显示最多前 512 单元，控制字符/换行改为空格、代理对保持完整；搜索仍使用原名称。
- 打开/搜索/选择候选不改变表格。确认可见列时“定位”，隐藏列时“显示并定位”，后者才显示该列并告知它会进入可见列导出范围。仅横向滚动，不更改行选择/焦点、排序、列宽/顺序、筛选、原值或 SQL。
- Enter 确认、Esc 取消；查询框上下键选候选。无匹配不确认。单标签不重复开窗，不持久化词或列信息。
- 窗口捕获列对象身份；列集合改变（含新结果或重排）后失效，禁止猜同名新列。无结果、忙碌/排队、关闭/终结、禁用和执行计划拒绝旧入口；隐藏状态变化需刷新按钮文案后再次明确确认，不能默默扩大导出列。
- 不扫描数据库、读取行内容、修改数据、执行 SQL、自动复制或导出；空行结果仍可定位列。

## 实施与验证

1. 增加独立列查找窗口，沿用现有对话框和 JavaFX 键盘模式；只接收表格与只读准入守卫。
2. 列菜单负责启动、重复窗口保护与释放，Pane 仅传入现有生命周期守卫并在 FX 终结释放菜单。
3. 测试重复/隐藏/长名称、空值边界、范围上限、取消与过期、真实横向滚动、实际 Pane 筛选排序/选择/原值不变；合成数据、独占临时目录和网络 probe。
4. 定向、全量 clean test、开发镜像及合成桌面验收；更新文档、审查后本地提交并快进 main，合并后回归。不推送/tag/发布，不触碰 `.testagent/`。
