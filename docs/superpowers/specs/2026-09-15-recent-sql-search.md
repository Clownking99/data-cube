# 最近 SQL 文件检索

基线 main `1cbfd4d`。本轮解决完整路径平铺菜单难以辨认同名脚本的问题：保留新建、打开和清空入口，将最近路径改为「最近文件…」列表。不扩大索引（仍最多 10 条），不增加工具栏按钮或快捷键配置。

列表按原最近顺序显示文件名与路径，选择后提供可选取的只读完整路径。按完整路径做忽略大小写的字面搜索，去除查询首尾空白，最多 256 UTF-16 单元；输入不打开文件。保留仍匹配的候选，候选被过滤掉后清空选择，不按旧索引换成另一个文件。↓ 明确选择首项/进入列表，Enter 或「打开」确认，Esc 取消，Ctrl+F 回筛选；路径预览 Enter 不打开。

列表使用打开时的路径快照，不检查文件存在性、读取正文、扫描目录或连接数据库。确认前复核候选仍在过滤列表、窗口允许操作；返回后复核路径仍属于原快照及当前最近索引，再交给现有 SqlFileEntry。失败、编码/限额、去重、未保存文本保护、离线会话和关闭准入规则不变。取消不写索引；「清空最近文件」仍仅清索引，不删 SQL。

实施：独立 worktree → 菜单入口 RED → 对话框与菜单最小接入 → 定向/全量测试 → 隔离合成桌面 → 本地提交并快进 main。测试技能按项目约定用于边界及行为证据，不使用通用流水线工件、不触碰用户 `.testagent/`。本轮不推送、打 tag 或使用业务文件。
