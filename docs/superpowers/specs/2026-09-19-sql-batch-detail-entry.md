# 当前批量结果的执行详情入口

基线 main `5b21ec3`。上一轮支持逐条结果切换，但查看对应 SQL/完整错误仍需切回概览再选择该行。本轮以此实际界面路径为依据，补齐结果追溯入口；没有新增用户耗时研究。

- “本次结果”选择器旁增加“执行详情”。选择具体语句时可打开该条只读 SQL、状态、耗时及错误；概览项禁用此按钮，沿用概览下现有逐行详情入口。
- 使用已捕获的 `SqlScriptExecutionReport.Entry`，按候选对象身份对应，不根据 SQL 文本、展示行号或当前编辑器内容重建。继续使用现有单段 16,384、合计 1,048,576 UTF-16 单元的有界快照；不复制查询数据进详情。
- 不执行、保存、复制或修改 SQL；不改变结果筛选、排序、列布局和选区。沿用只读窗口、事务提示、主题和关闭按钮/ESC。
- 重复打开保持一个窗口；切换选择、替换结果、清空、忙碌禁用或关闭时关闭旧详情。动作发生时再次检查主编辑器的执行/关闭守卫，旧按钮事件和已脱离的候选无效。
- 范围限于批量结果；不改变单条执行、分句器、继续策略、数据库访问或导出行为。测试与桌面使用合成数据和独立 profile，不访问 `.testagent/`、真实连接/配置/SQL 或系统剪贴板。

实施：新增入口回归并验证 RED → 在 `SqlBatchResults` 内接按钮/有界详情及生命周期 → 定向与全量测试、打包 → 隔离桌面鼠标/键盘/明暗窄窗 → 差异复核、提交并本地快进 main。无推送/tag/发布。
