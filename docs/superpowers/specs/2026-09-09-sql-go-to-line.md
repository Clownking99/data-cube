# SQL 跳转到行

## 决策与范围

基线 main `9a1e4a1`。当前 SQL 编辑器已显示行号和光标位置，但没有按行号直接定位入口。
本轮补充长脚本内的定位动作；这是基于现有工作流的产品判断，不代表已取得用户访谈或耗时改善数据。

- 编辑器底栏提供“跳转行…”按钮，默认 Ctrl+G，可在现有设置中改绑；不增加主工具栏按钮。
- 打开内嵌定位栏，默认选中当前行号，显示合法范围。Enter/“定位”跳到目标行首、滚动到光标并返回编辑器；Esc/“取消”关闭且保留原光标与选区。
- 仅接受首尾空白可忽略、最多 10 位的 ASCII 十进制正整数，范围 1..当前段落数；空文件也有第 1 行，末尾换行后的空行可以定位。空、零、负数、小数、非数字、溢出和超范围输入显示说明并禁用定位，不猜测或截断。
- 定位会折叠选区，因此明确告知“定位到行首并清除选区；下次执行为全部 SQL”。沿用既有执行范围提示，绝不自动执行。
- 定位栏和查找/替换栏互斥；打开定位先隐藏补全及查找，打开查找/替换则隐藏定位。切换/取消不接受补全、不修改 SQL。
- 可在无连接或只读 SQL 编辑器定位；文件操作忙、编辑器禁用、关闭中的动作不得生效。提交时按最新段落数复核，关闭时移除监听。
- 不新增数据库、文件 I/O、历史、草稿格式、事务或网络行为；定位只沿用已有工作区光标记录，不写 SQL 文件，不增加撤销项或未保存标记。
- 现有查找/替换快捷键判断优先级不变；旧配置若已使用 Ctrl+G，可继续原动作，通过底栏入口或重新配置无冲突组合键使用定位。

## 分步实施

1. 独立定位栏与有界数字判定，覆盖有效行/非法输入/正文变化/取消/关闭。
2. 接入底栏、快捷键、补全与查找互斥；验证文件不变、定位后执行范围、改绑与多标签隔离。
3. 明暗 480/640/880px 布局、定向和全量测试、开发镜像；隔离合成文件桌面验收。
4. 审查后提交并本地快进 main，不自动推送、tag 或发布；保留根目录用户 `.testagent/`。
