# 批量执行结果：下一异常

基线 main `b5510eb`。批量执行已提供逐条结果与直接详情，但失败汇总不提供定位动作，长批次仍需逐项查找。这是现有界面路径的产品推断，不是新增用户访谈或耗时研究。

- 在“本次结果”旁增加“下一异常”。只定位本次已保留结果中失败、超时、取消的语句，跳过正常查询/更新和概览；从当前项之后向前找，末尾回到第一项。概览从第一条异常开始。
- 定位只走原结果切换路径，显示对应错误，可再点“执行详情”；不自动弹详情，不改 SQL、不执行数据库操作。保留既有切换时重置结果筛选/列布局的语义。
- 没有其他可定位异常时禁用：无异常，或当前已是唯一异常。后者保留当前结果/详情，不重复重置。同一批次切回正常项/概览后可再次定位这一条。
- 只扫描已保留的前 1,000 项；第 1,001 项后的异常仍计入原汇总与截断提示，但不跳到未保留结果，也不扩大读取或重新执行。
- 沿用忙碌、禁用、关闭和候选身份守卫；按钮触发时重新计算目标，不捕获跨批次的旧索引。更换批次/新单结果/清空/关闭不复活旧结果。
- 不新增快捷键；支持原生 Tab/空格按钮操作。明暗窄窗需要保留完整按钮文字与可用选择器。

计划：补入口/顺序/循环/唯一异常/限额/守卫回归并验证 RED → `SqlBatchResults` 最小实现 → 定向/全量及开发镜像 → 独立 profile 的合成桌面检查 → 提交、本地快进 main 与集成验证。不触碰 `.testagent/`、真实配置/连接/SQL、系统剪贴板；不推送、打 tag 或发布。
