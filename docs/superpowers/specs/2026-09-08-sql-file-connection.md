# SQL 文件显式选择连接

## 产品决策

基线 `846618a`：`AppShell.SqlFileEntry` 为文件创建独立空 `SessionContext`，既不跟随左侧
全局连接，也没有草稿恢复的重新选连接入口；普通编辑器的“在左侧选择连接”提示在此场景不可完成。
本轮优先打通脚本复用流程，暂不增加替换、收藏、对象搜索或新的 SQL 执行方式。

- 仅显式打开的 SQL 文件标签提供“选择脚本连接”。不自动使用全局选中连接，不从正文推断目标。
- 选择框只列出已有 PostgreSQL / Oracle 配置，展示名称、类型和稳定 ID；没有默认选择。
  无可选配置时说明先新建关系型连接；取消保持原意图、SQL、Schema、文件状态不变。
- 选择只记录不含凭据的稳定 ID/类型/名称意图；复用草稿恢复已有的离线门禁。
  文件构造、选择、Schema 输入、关键字/成员补全、Ctrl+点击均不得连接或加载元数据。
- 确认时及首次操作准入时重查稳定 ID/类型。配置删除或改类型不能回退到同名或全局连接。
  同 ID/类型的更新使用最新配置及安全策略。选择后展示目标、环境和只读状态。
- 在首次执行、执行计划或显式事务操作前可重选；准入锁定后禁用更换，避免 SQL/事务漂移。
  继续使用原有专用会话、风险确认、取消和关闭流程，不添加自动执行。
- 关闭/资源释放后拒绝迟到的选择回调。文件内容、路径、dirty、保存规则不受选择影响。
- 若已有草稿保护，连接意图进入原有草稿检查点；不新增凭据、文件路径或 SQL 文件格式字段。

## 实施与验收

1. 新文件构造入口启用离线意图，复用现有门禁；新增文件选择入口并接入真实 AppShell 文件安装事务。
2. 共用现有连接选择组件，区分脚本与草稿文案，补齐空列表提示。
3. 回归真实安装入口、取消/空/Redis、稳定身份与变更、选择后全离线路径、首次准入锁定、关闭迟到回调，
   并保持现有草稿恢复和正常绑定编辑器行为。
4. 定向、全量测试与打包；独立 user.home、合成配置/SQL 桌面验收，不访问真实数据库。
5. 差异审查后按本任务继续集成的约定合并推送 main，检查同 SHA CI；不打 tag、不发布安装器。
