# 查找已打开标签

基线 main `25ba15f`，分支 `codex/open-tabs-search`。
现有 SQL、数据、DDL 等页面共享内容标签栏，标签多时需在横向标签栏查找。本轮补充按标题定位已有标签的显式入口；这是基于现有工作流的产品假设，没有用户耗时改善数据。

- 顶部“查找标签”打开模态选择器，空查询展示当前全部标签，默认高亮当前标签；无标签时入口禁用。
- 标题按忽略大小写的字面子串匹配，忽略查询首尾空白；不搜索 SQL 正文、结果、文件、历史或未恢复的工作区。查询上限 256 UTF-16 单元，超长明确拒绝，不截断查询。
- 展示原标签顺序编号及完整标题的提示，同名标签仍按对象身份区分。输入/方向键/单击仅选择候选，按“切换”或 Enter 才改变当前标签；取消/Esc 保持当前标签。
- 对话框存续时跟踪标签增删、标题及禁用状态。列表变化不自动改选另一个候选；原候选消失或不再匹配后须重新选择。过滤词变化可高亮首个匹配，但不切换主页面。
- 切换时重新检查归属、禁用状态及应用是否允许导航，拒绝已移除或关闭中的标签；不按标题替换目标，不修改既有关闭守卫。
- 不创建/关闭/重排标签，不读正文或剪贴板，不分配数据库服务、连接、会话或网络任务，不执行 SQL，不新增持久化格式。正常标签选择仍沿用已有页面生命周期及工作区选择记录。
- 关闭对话框后解除外部监听并封住旧动作；沿用主题，支持输入、方向键、Enter/Esc，不新增全局快捷键。
- 定向行为测试、全量测试及开发镜像、隔离桌面验收、审查后提交并本地快进 main。不自动推送/tag/发布；不读取或改动 `.testagent/`。
