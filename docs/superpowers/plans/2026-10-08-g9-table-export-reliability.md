本次静态审阅与隔离诊断确认：

1. `ExportDialog` 在任何导出异常后删除用户选中的目标；`TableExporter` 的 SQL/XLSX 直接打开目标写入。合成数据源中途失败时，两个真实 writer 均已改变旧文件字节。
2. `PgDumpRunner` 先读 stderr 到 EOF，再开始 `waitFor(10 min)`，等待期限不覆盖前面的阻塞读取；取消/异常缺少完整的进程所有权与回收结算。

## 产品契约

### G9a：目标文件保护

整表 SQL/XLSX/pg_dump 导出统一采用同目录独占临时文件与成功后的原子发布。优先复用已审核的安全发布机制，必要时小幅抽取通用能力，不削弱查询结果导出的现有保护。

目标选择/覆盖确认绑定实际目标身份；准备、连接、读取、序列化、关闭、发布、取消与清理失败均不得删除或截断原目标。只清理本次拥有的临时文件。目标期间变化、并发同目标、链接/别名和不支持原子替换等情况明确拒绝或安全失败；不得降级为直接覆盖。成功仅在实际发布完成后报告，失败可在重新确认目标后重试。

### G9b：pg_dump 与取消生命周期

从任务/进程启动建立总期限，独立有界排空输出，静默、持续输出和不换行输出均不能绕过期限或无限占用内存。取消、关闭、启动失败、非零退出和输出读取失败收敛到明确终态；只终止本任务拥有的进程/后代，回收流与工作线程，不误杀其他进程。

取消请求与实际停止、发布完成有清晰的先后关系；不能只关弹窗/抑制回调就报告取消。正常完成、截止边界、取消后迟到完成均最多结算一次，不发布半成品。使用本地可控 helper 证明，不调用真实 pg_dump 或真实数据库。参数使用结构化 argv，目标表保持精确身份，凭据不得进入命令行、日志或报告。

### G9c：完整一致的流式读取

导出拥有独立连接和明确目标配置快照，不借用连接树/其他标签的共享连接或事务。数据使用一次有界流式读取或能证明一致性的等价 provider 方案；不能继续依赖无序多次 OFFSET，也不能仅加 ORDER BY 就宣称并发一致。

空表列名、超过旧分页大小的数据、无主键表、取消/超时、配置变化和异常关闭均有明确契约。使用驱动支持的 fetch/事务策略控制内存，不把 UI 的行数/显示值截断当作完整导出。对无法可靠表示或超过约定边界的数据明确失败，不静默截断；保留现有 SQL/XLSX 内容选择和格式行为，不在本轮改造其他格式或扩大 SQL 方言兼容承诺。

JDBC cancel/close 仅作用于本任务资源；物理操作停止和连接/语句/结果集释放必须可观察。不得在 FX 线程等待阻塞 I/O，不改变其他 SQL 标签的事务、关闭或只读/生产门禁。G9 证明数据读取契约，不额外声称 DDL 与数据共同构成整个 Schema 的原子快照。

## 必须覆盖的验收矩阵

- 旧目标/新目标/无关邻居：连接前失败、首行前失败、中途读取/编码失败、流关闭失败、发布失败、取消；旧字节和邻居不变，没有假成功，临时文件归属与清理有证据。
- 目标确认后被替换、删除/重建、链接或别名、同目标并发、拒绝原子移动；不绕过现有查询结果保护。
- pg_dump helper：无输出挂起、stderr 大量/不换行输出、stdout 输出、非零退出、启动失败、取消与正常结束竞态、关闭后的迟到回调；受控进程/流实际结束。
- JDBC：独占连接、配置快照/失效、空表、超过 500 行、无主键、读中变化的可控 mock、异常与取消；无序分页不能作为实现，源流逐行消费，资源关闭计数和其他会话不受影响。
- UI：同一请求仅一个终态；取消后不得继续发布或假报成功；错误信息不暴露合成敏感值；重新选择/确认后可以重试。合成 FX 不冒充原生桌面。
- 回归：既有查询导出、安全发布、XML/XLSX 保真、事务取消/关闭、provider 及 task runner 相关定向，再完整工程验证。

mock 只能证明调用、边界、时序和资源所有权；真实 Oracle/PostgreSQL 的快照/驱动取消/网络行为及原生文件选择器、慢/网络磁盘仍单列待验，不由本轮 mock 自动关闭 G8。
