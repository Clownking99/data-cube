## 目标和范围

XML 导出当前会静默删除 NUL 等控制字符，允许部分不能组成 XML 1.0 文档的值，并以原始 CR/属性空白写出导致标准解析器回读改变内容。本轮仅修正查询结果 XML 序列化：可表示内容解析后保留原值；不可表示的值或列名明确失败，安全发布层保留已有文件，用户得到固定且不泄露内容的原因。

保留 ROWSET/ROW、空值省略、列名净化及 name 属性兼容结构，不改变其它格式、查询范围、截断策略、事务或 SQL 执行。初查导出发布同步锁候选已放弃：真实 tab 关闭先禁用内容，资源关闭在后台，不能宣称已发现 FX 关闭阻塞。

依据：[W3C XML 1.0 第五版](https://www.w3.org/TR/REC-xml/) 的字符范围、行尾处理及属性归一化。非法字符不能通过数字引用绕过；合法 CR 以及 name 属性中的制表符、换行需正确引用。行为以独立标准解析器回读和实际安全文件发布回归验证，不以输出片段自证。
