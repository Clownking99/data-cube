## 决策与边界

- 每个 SQL 标签最多固定 3 份已加载的查询结果；独立只读窗口查看来源 SQL、锁定连接的名称/ID、Schema 和固定时间。时间明确为固定时间，不冒充执行开始或数据库快照时间。
- 固定全部已加载行；不复制当前本地筛选、选区或列布局。原查询因行数/预算截断时继续显示原有提示。数据库筛选后的结果明确标明来源 SQL 是原始 SQL、参数未保留，不提供重新执行入口。
- 固定结果总计不超过 50,000 行、250,000 单元格、4,194,304 UTF-16 文本单元，每份至多 256 列，单文本至多 4,096，来源 SQL 至多 16,384。计入列标签/类型/注释、来源文字、原有省略提示及数值文字。超限原子拒绝，不驱逐旧结果、不静默截断新结果。
- 只引用经过预算核查的不可变 QueryResult，不保存整个批次、视图缓存、ConnConfig、会话、JDBC 资源或凭据。无法确定有界的复合表示拒绝固定；执行层已有 ResultValuePreview 继续可固定，保留“仅预览”语义。
- 当前执行预算和固定预算分别有界。显式数据库筛选最多同时保留原/新结果，再加固定预算；这不是整个 JVM 或驱动缓冲的字节保证，不增加堆大小。
- 固定结果仅在本标签内存，切换批次/清空当前结果/计划不释放；显式移除/清除固定/关闭释放，至多一个查看窗口。关闭或阻止操作后的迟到动作无效。
- 仅合成 profile、mock JDBC、临时目录；不读取 `.testagent/`、真实连接/SQL 历史/业务文件或凭据，不连接真库，不推送/tag/PR/安装/发布。
