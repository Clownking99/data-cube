## 范围与决策

- 复用真实产品控件与现有合成夹具；需要新夹具时只放 test 源集。使用独占临时 profile，阻断真实 JDBC，不读取已有连接、凭据、SQL 历史、业务文件或 `.testagent/`。
- 优先补 G7 迁移预检查/确认/报告的原生证据，再检查 SQL 编辑与结果、表格显式保存、收藏/检索、完整壳的离线流程。用键盘、明暗主题、窄窗和 JavaFX 100%/150% 输出比例观察；不把进程缩放参数写成 Windows 系统缩放/多屏验收。
- 原生交互只能使用 computer-use 的返回窗口与新鲜截图。模态窗口不受工具支持、桌面锁定或持续失败时停止该路径，原样记未验；不靠测试代码触发控件来冒充原生输入。
- 确定性产品问题先形成行为回归再最小修复。验收脚手架不加入生产开关或镜像配置，不新增数据库或格式化扩展。
- 定向回归、全量、强制 buildSrc 测试和 jpackageImage 必须是本轮执行。审查后本地提交、合并 main 并复验，证据区分基线、最终分支与 main。
- 真库、签名、安装升级、远端 CI、推送/tag/PR/发布、用户邀请均不在授权范围；真实用户任务、多屏和未完成原生路径单列，不自动勾选总体 M8。
