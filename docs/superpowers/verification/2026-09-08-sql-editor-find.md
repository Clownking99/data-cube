# SQL 脚本内查找验证

## 范围与隔离

- 只查找当前 SQL 标签文本；不增加替换、正则、跨文件搜索或 SQL 执行路径。
- 新增独立匹配器、查找栏和 `sql.find` 快捷键；复用现有任务作用域及两阶段关闭。
- 测试使用合成 SQL、临时文件、无连接编辑器；不读取真实连接、历史或凭据。
- 桌面测试包使用 `-PappVersion=0.0.0` 和 worktree 下独立 `user.home`，不修改发布版本。

## 自动回归

- `SqlTextSearchTest`：字面符号、Unicode/UTF-16 范围、大小写、空/无匹配、非重叠导航、
  首尾循环、9,999/10,000/10,001 数量边界、1,024 长度边界、取消和不可变结果。
- `SqlFindBarTest`：实际 150ms 防抖、CodeArea 只读导航及撤销栈、Enter/Shift+Enter、
  查询更新、空/过长/无匹配提示、大小写切换、取消、模拟取消前已排队的迟到回调、
  隐藏/关闭后的隔离、数量截断与固定失败提示。
- `SqlEditorUsabilityTest`：按钮入口、Ctrl+F 及即时改绑、未绑定编辑器不执行 SQL、不改写文件；
  880/640/480px × 深/浅主题下的控件边界、编辑区不被覆盖、关闭后归还空间。
- 既有保存默认值、主工具栏、自动补全焦点、会话关闭、脚本文件控制器定向回归通过。

首次匹配器测试在实现前因缺失 `SqlTextSearch` 类型失败。实现阶段修正了查找栏监听器字段
的前向引用编译错误。新增布局断言在 640px 的两种主题下捕获初版 FlowPane 高度低估：
查找栏边界 Y=199..233，输入框 Y=192..218。将状态提示移出控件 FlowPane、置于独立
可折行行后，同一组断言通过；没有放宽边界断言。

```powershell
.\gradlew.bat clean test jpackageImage '-PappVersion=0.0.0' --no-daemon --console=plain
```

## Windows 实际窗口

最初桌面操作返回访问拒绝后停止，用户确认解锁后继续。使用最终重新构建的
`build/jpackage/DataCube/DataCube.exe`，独立配置内无保存连接。合成文件名包含中文与空格，
内容为三行含 `select` / `SELECT` 的 SQL，不执行语句。

- Ctrl+O 打开合成文件，编辑器显示未绑定连接，执行按钮禁用。
- Ctrl+F 显示并聚焦查找框；输入 `select` 后显示“共 3 处”，文本选择不自动跳转。
- Enter 依次定位第二、第三、第一处；循环提示“1 / 3 · 已回到开头”。
- Shift+Enter 反向回到第三处，显示“3 / 3 · 已回到末尾”。
- 勾选区分大小写后显示“共 2 处”，排除大写 `SELECT`。
- 拖动连接栏分隔条，核对约 640px 和 480px 编辑宽度；控件换行、状态独占一行，
  不覆盖 SQL。窄布局仍能点击下一处并循环。
- 切换亮色主题后窄布局仍可读；Esc 隐藏查找并归还编辑空间。
- 点击工具栏“查找”再次打开，预填并选中 SQL 中选中的 `select`；恢复正常编辑宽度。
- 全程标签无未保存星号，原文件 SHA-256 保持
  `5B5B64B386F549123DD95638EB5BF99ACBC7B4F452ED834FBB83B974531F9FC2`。
- 正常关闭本轮测试窗口；没有触碰用户实际数据库配置。

## 已知边界

- 字面查找不重叠，默认 Unicode 大小写不敏感；不是语言区域规则、正则或全文索引。
- 匹配上限 10,000；存在第 10,001 处时才显示 `10000+`，仅在前 10,000 处导航。
- 查询最多 1,024 个 UTF-16 单元，超长不截断、不提交；结果状态不记录正文或内部异常。
- 本轮不对真实数据库连通性或查询结果作额外声明。
