# DataCube 下一版本候选变更说明

> 这是发布前候选说明，不是发布公告。最终版本号将在发布前确定；请勿将本地默认值 `3.0.0` 视为新的发布版本号。

## 查询结果导出

- 导出范围可选择“当前筛选结果（当前排序）”或“全部已加载行（加载顺序）”。两种方式都只导出当前可见列及其顺序，不会为导出重新查询数据库。
- 当结果中含有 CLOB 或其他特殊值时，界面会先说明受限预览和导出影响，并要求确认。无法无损生成 `INSERT` 的值会拒绝生成 SQL，而不会输出可能丢失信息的 SQL 脚本。
- XLSX 查询导出改善了列宽、表头样式与首行冻结，使长中文和时间值更易阅读；这不代表已经完成对所有 Microsoft Excel 版本或交互行为的验收。

## 已知限制与未完成项

- 当前查询结果表尚无显示/隐藏列入口；导出的可见列规则已有内部契约测试，但不能据此宣称用户可以隐藏列。
- 全部已加载行范围的切换后保存、部分独立确认弹窗的键盘操作，以及搜索防抖尚未结束时立即导出，仍待桌面补验。
- 五种格式已有实际保存证据，但未覆盖每种“范围 × 格式 × 值类型”组合。XLSX 的数据与布局已核对；真实 Excel 的滚动冻结和自动行高仍未验收。
- 大字段仅保留有界预览；导出不会再次通过 JDBC 读取。大字段在真实数据库中的延迟尚未验证。

## 谨慎回退

如需回退，请先退出 DataCube，并由您自行备份本地配置与已生成的导出文件；保留这些文件以便核对。之后按组织的既定安装或部署流程恢复到先前版本。不同版本之间不保证配置或导出文件的降级兼容性，回退后请重新检查连接配置和导出结果。
