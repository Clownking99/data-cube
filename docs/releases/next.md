# DataCube 下一版本候选变更说明

> 这是发布前候选说明，不是发布公告。最终版本号将在发布前确定；请勿将本地默认值 `3.0.0` 视为新的发布版本号。

## 查询结果导出

- 导出范围可选择“当前筛选结果（当前排序）”或“全部已加载行（加载顺序）”。两种方式都只导出当前可见列及其顺序，不会为导出重新查询数据库。
- 当结果中含有 CLOB 或其他特殊值时，界面会先说明受限预览和导出影响，并要求确认。无法无损生成 `INSERT` 的值会拒绝生成 SQL，而不会输出可能丢失信息的 SQL 脚本。
- XLSX 查询导出改善了列宽、表头样式与首行冻结，使长中文和时间值更易阅读；这不代表已经完成对所有 Microsoft Excel 版本或交互行为的验收。
- 结果工具栏提供“列（可见/全部）”菜单，可隐藏列或显示全部，至少保留一列。本地搜索和筛选保留列顺序、宽度、可见性与排序；新查询结果重置，不跨会话保存列偏好。

## SQL 草稿恢复

- SQL 编辑器提供本机自动保存状态和独立“SQL 草稿”入口。显式选择后预览、恢复；已打开的草稿定位到原标签。恢复不自动连接数据库、读取元数据或执行 SQL，也不恢复结果集和事务。
- 缺失连接保留文本，支持显式重新选择；按稳定连接 ID 和数据库类型匹配，不用同名连接代替。
- 草稿默认开启，可关闭或清空。SQL 文本可能含敏感信息，文件不是加密存储；关闭/清空草稿不等于关闭/清空原有 SQL 历史。
- 停顿约 1 秒、持续输入约 10 秒触发快照调度；实际保存受磁盘与故障影响，异常退出仅能恢复已经成功保存的检查点，不承诺零丢失。

## 已知限制与未完成项

- 草稿管理、关闭保护和离线恢复已通过单元/集成回归及任务级审查；独立进程与打包也已通过。整分支审查中的失败分类和残留文件提示已修订并重新验证，正在独立复审；桌面捕获/访问受系统限制，实际主题和交互尚未验收。此候选说明不代表已发布或完整发布门槛通过。

- 显示/隐藏列入口已通过合成数据桌面观察，两种导出范围的可见列 CSV 内容有自动化文件验证；隐藏列后的确认摘要已核对，但该组合的桌面文件保存尚未补验。
- 全部已加载行范围的切换后保存、部分独立确认弹窗的键盘操作，以及搜索防抖尚未结束时立即导出，仍待桌面补验。
- 五种格式已有实际保存证据，但未覆盖每种“范围 × 格式 × 值类型”组合。XLSX 的数据与布局已核对；真实 Excel 的滚动冻结和自动行高仍未验收。
- 大字段仅保留有界预览；导出不会再次通过 JDBC 读取。大字段在真实数据库中的延迟尚未验证。

## 谨慎回退

如需回退，请先退出 DataCube，并由您自行备份本地配置与已生成的导出文件；保留这些文件以便核对。之后按组织的既定安装或部署流程恢复到先前版本。不同版本之间不保证配置或导出文件的降级兼容性，回退后请重新检查连接配置和导出结果。
